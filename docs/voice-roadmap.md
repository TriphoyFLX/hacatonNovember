# Локальный голос

Кнопка «Слушать» на странице «Голос» запускает локальный Vosk (модель `vosk-model-small-ru-0.22`). Процесс шлёт только текст и уверенность. Ядро выбирает команду через `intent_from_phrase` и тот же allowlist, что и жесты.

Микрофон не включается при старте. Пауза и аварийная остановка закрывают микрофон и делают `ReleaseAll`. Курсор по-прежнему включается отдельно. Незнакомая фраза ничего не нажимает. Облака и shell нет.

Модель скачивает `scripts/setup.ps1` или `setup.ps1` рядом с exe. В git и в установщик она не входит.

## Доверие

- Как и vision: внешний процесс шлёт **только текст** и уверенность.
- Ядро само выбирает команду через `intent_from_phrase` / allowlist.
- Без shell, без облака, без elevated API.
- Управление курсором остаётся выключенным, пока пользователь не включит control; pause / emergency делают `ReleaseAll`.

## Протокол

```json
{"version":1,"type":"voice","text":"открой проводник","confidence":0.88}
```

Парсер: `parse_voice_line` / `Incoming::Voice`. Intent-stub: `air_control_core::voice::interpret_line`.

## Не входит

- Облачные API речи.
- Произвольные shell/команды из фразы.
- Автозапуск микрофона при старте приложения.
