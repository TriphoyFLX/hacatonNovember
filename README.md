# AIR CONTROL

Feel the digital world.

Бесконтактное управление Windows с обычной веб-камеры. Рука отслеживается локально, жесты превращаются в курсор, клики, прокрутку, громкость и команды окон. Кадры на сервер не отправляются.

## Что умеет

- Курсор кончиком указательного пальца, с One Euro Filter, мёртвой зоной и коротким ускорением, которое возвращается к позиции пальца.
- Короткий щипок — левый клик. Щипок с движением — перетаскивание. Два коротких щипка подряд Windows получает как двойной клик.
- Правый клик знаком V, прокрутка свайпом, громкость большим пальцем.
- Две руки: ведущая рука держит курсор, вторая регулирует громкость. Две открытые ладони меняют масштаб или переключают рабочий стол.
- Профили Рабочий стол, Браузер, Презентация, Медиа и воздушная клавиатура. Автовыбор смотрит на имя процесса активного окна. Незнакомое приложение остаётся в профиле рабочего стола.
- Свои жесты: запись шаблона и сравнение динамическим выравниванием. Это не обучение модели.
- Калибровка измеряет зону руки, размах пальцев и порог щипка. MediaPipe при этом не дообучается.
- Пауза кнопкой или Ctrl+Shift+F12. Аварийная остановка отпускает кнопки. Удержание мыши дольше 8 секунд снимается само.

Команды идут только через диспетчер и белый список. Жест не может открыть shell, запустить программу или повысить права.

## Требования

- Windows 10 или 11, 64-bit
- Rust stable
- Python 3.11 или 3.12. Python 3.14 не подходит: для него нет колеса MediaPipe
- Веб-камера

## Установка

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
cargo build --release -p air-control-app
powershell -ExecutionPolicy Bypass -File scripts\run.ps1
```

`setup.ps1` создаёт `vision\.venv`, ставит MediaPipe и OpenCV и скачивает `hand_landmarker.task`. Модель и виртуальное окружение в git не входят.

Сборка папки для переноса:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\package.ps1
```

Если установлен Inno Setup 6, скрипт дополнительно собирает `dist\AirControl-Setup.exe`. Без него остаётся папка `dist\AirControl`. На новом компьютере в этой папке всё равно нужен `setup.ps1`, если рядом нет `.venv` и файла модели.

## Как показать

1. Запустите приложение. Камера и управление выключены.
2. Нажмите «Включить камеру» и дождитесь скелета руки.
3. Нажмите «Разрешить управление».
4. Указательный палец двигает курсор. Короткий щипок нажимает. Удерживайте щипок и сдвиньте руку, чтобы перетащить.
5. Свайп вверх или вниз прокручивает. Ctrl+Shift+F12 или «Аварийная остановка» возвращает обычную мышь.

Чувствительность, плавность, ускорение и порог уверенности находятся в разделе «Управление». Свои жесты и команды — в «Студии жестов».

## Архитектура

```text
камера → Python (OpenCV + MediaPipe Hand Landmarker)
      → JSON Lines, протокол версии 1, только ориентиры и статус
      → Rust: жесты, курсор, безопасность, диспетчер
      → поток ввода: Enigo и Win32
      → интерфейс Slint показывает снимок состояния
```

Процесс зрения не имеет права прислать системную команду. Устаревшие кадры не копятся: в Rust остаётся последний пакет слежения. Настройки, калибровка, профили, шаблоны и статистика лежат в `%LOCALAPPDATA%\AirControl`. Журнал — в подпапке `logs`.

Облачный backend в этом репозитории не создавался: исходный каталог был пуст, а камера по умолчанию не должна никуда уходить. Синхронизация настроек поэтому выключена, а не имитируется.

## Проверки

```powershell
cargo test --workspace
vision\.venv\Scripts\python.exe -m unittest discover -s vision\tests
```

Тесты проверяют геометрию жестов, фильтр, преобразование координат, белый список команд, паузу, шаблоны, повреждённый JSON и совпадение Python-сообщения со схемой Rust. Они не двигают вашу мышь. Числа задержки в интерфейсе — измерения текущей сессии; фиксированный паспорт производительности не публикуется.

## Если что-то не так

- «Python 3.11 не найден» — повторите `scripts\setup.ps1`.
- «нет файла модели» — setup не докачал `vision\models\hand_landmarker.task`.
- Камера потеряна — процесс зрения переподключается сам и пишет причину в диагностику.
- Жест виден, но команда не уходит — управление выключено, стоит пауза, уверенность ниже порога или ещё не прошёл cooldown.
- Окно программы не сворачивается собственным жестом специально.
