# AIR CONTROL

Desktop-приложение на Rust + Slint и локальном MediaPipe. Рука перед веб-камерой двигает курсор, кликает, перетаскивает и запускает сцену с инструментами. Кадры не уходят с компьютера.

Поддерживаются **Windows** (основная платформа) и **macOS** (сборка и разработка; ввод через Accessibility).

## Windows

```powershell
.\start.cmd
```

Нужны Rust stable и Python 3.11 или 3.12.

## macOS

```bash
# Xcode CLT + Homebrew Python 3.11/3.12
xcode-select --install
brew install python@3.12 rust

chmod +x scripts/setup.sh scripts/run.sh
./scripts/setup.sh
cargo build -p air-control-app
./scripts/run.sh
```

После первого запуска:

1. Разрешите **камеру** для `air-control`.
2. В **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** добавьте бинарь/`Terminal`/`Cursor`, иначе Enigo не сможет двигать мышь.
3. Гитара играет встроенный WAV-семпл через системный аудиовыход. Для пианино и барабанов подключите MIDI-выход или включите **IAC Driver** в Audio MIDI Setup.

Опционально укажите интерпретатор:

```bash
export AIR_CONTROL_PYTHON="$PWD/vision/.venv/bin/python"
export AIR_CONTROL_ROOT="$PWD"
```

Глобальная пауза `Ctrl+Shift+F12` сейчас только на Windows; на Mac — кнопка паузы в окне.

## Жесты

- Указательный палец двигает курсор. Сглаживание — One Euro Filter по всем осям, плюс короткое предсказание по задержке потока. Глубина (размер ладони и world-z) меняет скорость и слегка тянет прицел: ближе к камере — спокойнее.
- Указательный двигает курсор. Небольшой сгиб того же пальца — левый клик. Сгиб с движением — перетаскивание. Два сгиба подряд — двойной клик.
- Знак V — правый клик. Свайп вверх и вниз — прокрутка.
- На подходящих наборах большой палец меняет громкость; жесты зависят от активного профиля.
- Страница «Музыкальные инструменты»: пианино, ударные и гитара с 16 аккордами, режимом соло на 12 ладах, каподастром и пятью тембрами. На гитаре можно щипать струны рукой перед камерой или кнопками предпрослушивания; свайп играет боем. Гитарный WAV-семпл встроен в приложение и транспонируется для каждой ноты, MIDI остаётся запасным выходом.
- Профили выбираются по имени процесса активного окна.
- Набор «Рабочий стол»: большой палец меняет громкость, свайп ладонью влево или вправо переключает окно (Alt+Tab). На «Медиа» тот же палец тоже громкость, а боковой свайп меняет трек. На других наборах то же движение делает другое — список на странице «Что умеет рука».
- Две руки: ведущая держит курсор, а вторая на наборе «Рабочий стол» переключает окно вместо регулировки громкости.
- Набор выбирается по имени процесса активного окна. Свои правила — страница «Разные программы».
- Свой жест — записанный шаблон и динамическое выравнивание, не обучение модели.
- Калибровка запоминает вашу руку: ладонь, указательный, щипок, большой, зона, проверка и тренировка.
- Пауза: кнопка или Ctrl+Shift+F12 (Windows). Аварийная остановка отпускает кнопки.
- Голос локальный и только по кнопке «Слушать». Короткие русские фразы из списка на странице «Голос» идут в тот же белый список команд. Незнакомая фраза ничего не нажимает. Пауза выключает микрофон.

Команды проходят через один диспетчер и белый список. Жест не запускает shell и не повышает права. Настройки пишутся сразу в `%LOCALAPPDATA%\AirControl`.

## Готовая папка (Windows)

После `scripts\package.ps1` рядом с `dist\AirControl\air-control.exe` лежит `setup.ps1`. На чистой машине его нужно запустить один раз: он ставит Python-окружение камеры и голоса (3.11 или 3.12), модель руки и русскую модель Vosk. Установщик предлагает этот шаг после копирования файлов. Связка `.venv` из репозитория в установленную копию не переносится. Модель голоса в установщик не вшита — её скачивает `setup.ps1`.
