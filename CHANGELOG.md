# CHANGELOG

## 0.9.0 — unreleased

### Добавлено
- `.gitignore`: добавлена папка `dist/` — артефакты сборки больше не тянутся в git.
- `UserSettings.config_version`: версия формата конфига. При смене формата `store::migrate_settings` проводит миграцию вместо тихого сброса к дефолту.
- `UserSettings.setup_done`: флаг первичной настройки (модели скачаны, камера разрешена). Готовит почву для экрана онбординга при первом запуске.
- `CHANGELOG.md`: этот файл.

### Исправлено
- `store::load_all` теперь пропускает загруженные настройки через `migrate_settings`, чтобы старые конфиги не ломались после обновления.
